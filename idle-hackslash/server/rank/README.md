# ランキング API（XSERVER）

Firebase の無料枠（1日の読み書き回数）を気にしなくてよいように、ランキングを XSERVER の PHP + MySQL で動かす。

- `api.php` … ランキングの読み書き
- `mcp.php` … Claude（claude.ai）のコネクタ用の窓口。Claude のプレビュー（アーティファクト）は外へ直接つなげないので、これを通して読み書きする（中身は api.php と同じ）
- `admin.php` … 管理画面（ありえない記録の人を止める・シャドウバン（本人にだけ見える）・消す・名前を消す。パスワードは config.php の admin_pass）
- `config.sample.php` … DB の設定の見本。コピーして `config.php` を作る（**リポジトリに入れない**）
- `schema.sql` … 表を作る SQL
- `.htaccess` … api.php・admin.php 以外を外から見えなくする

## 置き方
1. サーバーパネル →「MySQL設定」で、データベースと MySQL ユーザーを作り、ユーザーにそのデータベースの権限を付ける。
2. サーバーパネル →「phpMyAdmin」でそのデータベースを開き、「SQL」に `schema.sql` の中身を貼って実行。
3. `config.sample.php` をコピーして `config.php` を作り、MySQL のホスト名・データベース名・ユーザー名・パスワードを入れる。
4. ファイルマネージャか FTP で、`public_html/mugen-rank/` などに `api.php`・`config.php`・`.htaccess` を置く。
5. ブラウザで `https://（ドメイン）/mugen-rank/api.php?a=count` を開いて `{"ok":true,"count":0}` が出れば OK。
6. その URL を `src/js/rank-server.js` の `RANK_API_URL` に入れてビルドする（アプリは https のみ。SSL を有効にしておく）。

PHP は 7.4 以上（8 系推奨）。

## 署名（ずる防止）
- アプリの書き込みには署名を付ける（HMAC-SHA256）。署名が付いていて合わないものは断る。パソコン（ブラウザ）版は鍵を入れられないので署名なしで送り、サーバーはそれも受け付ける（版に「web」が付く）。鍵は64桁の英数字で、**リポジトリには入れない**。
  - サーバー：config.php の `sign_key`
  - アプリ：`app/rank-key.txt`（gitignore 済み）。`npx cap sync` のあと自動でアプリの中に入る（tools/rank-key-copy.js）
  - GitHub Actions で組み立てるとき：Secrets の `RANK_SIGN_KEY`
- 鍵をなくしたら、新しい鍵を作って3か所とも入れ替える（古いアプリはランキングに書き込めなくなる）。

## 送る回数（1人あたり）
- 本日のクリア数：変わったときだけ、最短1分に1回
- ベスト記録：変わったときだけ、最短5分に1回（ランキングを開いたときは、すぐ1回）
- アプリを裏に回したとき・閉じるときも、すぐ1回送る
- サーバー側でも、同じ人のベスト記録の書き込みは3秒に1回まで（早すぎたものは skipped を返し、アプリは次にまた送る）

## 要確認の見張り（印を付けるだけ。api.php の先頭の数字で調整）
- ジェムが1回の書き込みで1万個以上増えた
- 転生回数が1回の書き込みで100回以上増えた
- 登録して1日目に、コイン（最高所持）が1回の書き込みで100億枚以上増えた
- 自動でシャドウバンしたり書き込みを断ったりはしない。管理画面の「⚠ 要確認」で見て、問題なければ「確認済み」、ずるなら「シャドウバン」「止める」

## Claude のプレビューで本物のランキングを見る（コネクタ）
1. `mcp.php` と、`mcp.php` を許可した `.htaccess` をサーバーに置く。
2. claude.ai の 設定 → コネクタ →「カスタムコネクタを追加」で、名前 **Mugen Ranking**（このとおり）、URL `https://hisashiapp.xsrv.jp/mugen-rank/mcp.php` を登録する（認証なし）。
3. アーティファクトを開くと、最初の1回だけ「Mugen Ranking を使ってよいか」を聞かれるので許可する。
- 登録した本人の claude.ai でだけ有効。登録していない人のプレビューは見本のランキングになる。
